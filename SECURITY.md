# Security policy

## Reporting a vulnerability

Please do not publish exploitable security details, credentials, access tokens, private customer information, or real account data in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. Otherwise, contact the maintainer privately through the [GitHub profile](https://github.com/wondxpt) or [LinkedIn](https://www.linkedin.com/in/abbas-shiri-453690248/).

Include the affected app and version, a concise description of the impact, and minimal reproduction steps using synthetic data. Redact logs and screenshots before sharing them.

Please allow time for investigation before publicly disclosing an unpatched issue.

## Sensitive information

- Never include passwords, one-time codes, access tokens, signing keys, keystore files, or private configuration in issues.
- Remove personal data from screenshots and logs.
- Do not share private customer or business records.
- A reported APK signature problem should include the app version and file checksum, not private signing material.
